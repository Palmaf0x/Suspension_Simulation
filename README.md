# Suspension Simulation

A Python project for simulating and optimizing vehicle suspension systems.
Includes physics models, parameter optimization, and API endpoints for running simulations.

## Features
- Suspension physics simulation
- Parameter optimization (solver + constraints)
- API for running simulations
- Modular architecture (analysis, optimizer, services)

## Structure
- `api/` → API routes
- `analysis/` → data analysis tools
- `optimizer/` → parameter solver and constraints
- `physics/` → simulation models
- `services/` → business logic
- `utils/` → Make CSV and JSON files
